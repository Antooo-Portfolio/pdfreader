Nouveautés de PDFReader 0.3.0, lecteur PDF gratuit pour Windows 10 et 11 (64 bits).

- Lire : propriétés du document, retour à la vue précédente (Alt+← / Alt+→), mode lecture (Ctrl+H) et plein écran (F11), lecture à voix haute, export et import de vos réglages.
- Chercher et naviguer : recherche avancée avec extraits (casse, mot entier), pièces jointes (enregistrer, ouvrir les PDF joints), vue protégée en lecture seule pour les fichiers venus d'Internet.
- Commenter : formes (rectangle, ellipse, ligne, flèche, polygone, nuage), tampons prédéfinis (Approuvé, Brouillon, Confidentiel…), réponses, statuts (Accepté, Refusé…) et coches.
- Signets : créer, renommer, déplacer, imbriquer et supprimer, enregistrés dans le PDF ; barre d'outils personnalisable.
- Formulaires : calculs et vérifications (totaux, plages de valeurs, nombres attendus) ; les scripts du document tournent dans un espace isolé, sans accès à l'ordinateur, et peuvent être coupés dans les Préférences.
- Plus solide : le moteur PDF tourne dans un processus séparé. S'il plante sur un fichier piégé, PDFReader reste ouvert, relance le moteur et rouvre vos documents.
- Nouveau : un setup hors ligne (fichier « offline-setup », environ 220 Mo) pour les ordinateurs sans Internet.

Mise à jour depuis la 0.2.0 : PDFReader la propose de lui-même si vous avez accepté la recherche de mises à jour ; sinon, installez simplement le nouveau setup par-dessus. Vos réglages, signatures et récents sont conservés.

What's new in PDFReader 0.3.0: document properties, back/forward navigation, reading and full-screen modes, read aloud, settings export and import; advanced search with snippets, attachments, protected view for files from the Internet; shapes, preset stamps, replies and review statuses; editable bookmarks and a customisable toolbar; form calculations and checks in an isolated sandbox; a separate, restartable PDF engine so a malicious file cannot take the app down; and a new offline installer for computers without Internet.
