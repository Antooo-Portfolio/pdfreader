Nouveautés de PDFReader 0.5.0, lecteur PDF gratuit pour Windows 10 et 11 (64 bits).

- Réduire la taille d'un PDF : niveaux écran, standard, impression ou sans perte ; les images plus fines que nécessaire sont réduites, le texte et les dessins restent nets. Dans une copie ou à la place du fichier.
- Écrire dans la page : du vrai texte ajouté au contenu (sélectionnable, cherchable, imprimé), avec police, gras, italique, taille et couleur ; à déplacer (glisser ou flèches), modifier ou effacer ensuite.
- Modifier le texte existant, ligne par ligne : la police d'origine est gardée quand elle contient les caractères voulus, sinon une police proche prend le relais (message) ; annuler avec Ctrl+Z. Les lignes voisines ne sont pas remises en page.
- Correction : après un enregistrement, une page modifiée ensuite pouvait rester affichée dans son ancien état. Elle s'affiche désormais toujours à jour.

Mise à jour depuis la 0.4.0 : PDFReader la propose de lui-même si vous avez accepté la recherche de mises à jour ; sinon, installez simplement le nouveau setup par-dessus. Vos réglages, signatures et récents sont conservés.

What's new in PDFReader 0.5.0: reduce PDF file size (screen, standard, print or lossless); write real text into pages (font, bold, italic, size, colour; move, edit or delete it later); edit existing text line by line (original font kept when it has the characters, a similar font otherwise; undo with Ctrl+Z); fix: after saving, a page changed afterwards could stay displayed in its old state.
