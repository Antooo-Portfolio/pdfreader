Computer without Internet? Take the offline version from the same page, PDFReader_x.y.z_x64-offline-setup.exe (about 220 MB): it contains Microsoft's WebView2 installer, the Windows component that displays the interface, and installs it if it is missing. Windows 11 already has it; the normal version downloads it when needed.

What it does

  • Read: tabs, search, thumbnails, bookmarks, one or two pages, rotation, dark theme.
  • Annotate: highlight, underline, strike through, notes, drawing, text boxes, callouts.
  • Fill and sign: forms, free text, ticks, typed, drawn or image signature.
  • Print: page ranges, scale, two-sided, with or without comments.
  • Accessible: full keyboard use, screen readers, high contrast, interface size.
  • Safe: nothing is sent, no telemetry, recovery after a crash.

First launch: the Windows warning

PDFReader is free and its installer is not signed with a paid certificate. Windows may therefore show “Windows protected your PC” the first time. To install:

  1. Click More info.
  2. Check that the file is called PDFReader_x.y.z_x64-setup.exe.
  3. Click Run anyway.

Later updates, if you accept them, are downloaded by PDFReader itself and checked with a digital signature before being installed.

Your data

PDFReader works entirely on your computer. The only possible connection is the update check, which you accept or decline on first launch. Privacy policy.
