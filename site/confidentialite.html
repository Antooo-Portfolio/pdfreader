PDFReader

Politique de confidentialité

Version du 12 novembre 2026.

En bref

PDFReader ne collecte aucune donnée personnelle. Tout se passe sur votre ordinateur.

Ce qui reste sur votre ordinateur

  • Vos documents et ce que vous y ajoutez (commentaires, champs remplis, signatures).
  • La liste des fichiers récents, l'état de vue de chaque document, vos préférences, votre signature et vos initiales, les copies de récupération : dans le dossier de données de l'application (%APPDATA%\app.pdfreader.desktop). La désinstallation vous propose de les supprimer.

Ce qui est envoyé

Rien, sauf la recherche de mises à jour, et seulement si vous l'avez acceptée au premier lancement ou si vous cliquez sur « Rechercher des mises à jour ». PDFReader demande alors à GitHub (hébergeur des versions) le fichier qui décrit la dernière version. Cette demande contient le numéro de version de PDFReader et le type de système ; comme toute connexion, elle laisse votre adresse IP à GitHub, qui la traite selon sa propre politique de confidentialité. Aucun identifiant, aucune statistique, aucun contenu de document n'est envoyé.

Liens dans les documents

Un lien vers un site web ne s'ouvre qu'après votre confirmation, dans votre navigateur.

Vos droits

Aucune donnée vous concernant n'étant collectée, il n'y a rien à consulter, rectifier ou supprimer chez nous. Pour toute question : la page des versions sur GitHub.

Privacy policy

Version of 12 November 2026.

In short

PDFReader collects no personal data. Everything happens on your computer.

What stays on your computer

  • Your documents and what you add to them (comments, filled-in fields, signatures).
  • The recent file list, each document's view state, your preferences, your signature and initials, recovery copies: in the application data folder (%APPDATA%\app.pdfreader.desktop). Uninstalling offers to delete them.

What is sent

Nothing, except the update check, and only if you accepted it on first launch or click “Check for updates”. PDFReader then asks GitHub (which hosts the releases) for the file describing the latest version. This request contains the PDFReader version and the type of system; like any connection, it gives GitHub your IP address, which GitHub handles under its own privacy policy. No identifier, no statistics and no document content is sent.

Links in documents

A link to a website only opens after you confirm, in your browser.

Your rights

As no data about you is collected, there is nothing for us to access, correct or delete. For any question: the releases page on GitHub.
